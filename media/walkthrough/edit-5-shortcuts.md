# Shortcuts and Commands

| Shortcut | Action |
|---|---|
| `Ctrl+Alt+R` | Renumber lines |
| `Ctrl+/` | Toggle remark |
| `Ctrl+Alt+L` | Go to Label |
| `Ctrl+Alt+F` | Show Program Flow |
| `Ctrl+Shift+B` | Compile KAREL |

**What Can I Do Here?** opens one picker with every command, grouped by what you are trying to do, each with its shortcut.

**You should see** a picker with headings like *Edit this TP program* and *Positions and frames*.
