# Turn On Robot Connections

Talking to a robot - reading files over FTP/HTTP, teaching, uploading - is still being proven on real cells, so it sits behind an **experimental switch**, off by default. With it off, nothing in Robot Code sends a single request to a controller.

**You should see** the **Cell** view appear in the Robot Code panel, and a status-bar note that robot connections are on.

[Turn On Robot Connections](command:robotCode.experimental.enableRobotConnections)

Turn it off again any time in **Settings > Robot Code > Experimental: Robot Connections**.
