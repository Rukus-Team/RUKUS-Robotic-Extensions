# Hand Off Monitoring, Alarms, Backups

The robot page's cards open RUKUS on the right page:

- **Live Monitor** - position, I/O and program state, kept live by RUKUS
- **Alarm History** - the alarm log, filtering and trends
- **Backups and Schedules** - RUKUS's dated backup history

A failed push can open RUKUS's **Error Watcher** too. Robot Code holds no connection open for any of these.

**You should see** RUKUS open on its Live Monitor page.

[Live Monitor in RUKUS](command:robotCode.rukus.monitor)
