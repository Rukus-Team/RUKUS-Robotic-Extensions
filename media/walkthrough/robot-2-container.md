# Initialize a Robot Container

A robot container is a `.robocode-robot/` folder that says "these are this robot's editable programs, and its snapshot lives here". The wizard finds backups for you and leaves them out of the editable set.

**You should see** a `.robocode-robot/robot.json` beside the folder you picked, and the working folders you ticked listed in **Programs**.
