# KAREL and Data Files

Open `S002R01/KL/HELLO.KL`: hover a built-in, go to a definition, and run the pre-compile lint before ktrans.

`.va` dumps (like `numreg.va`) power the register, I/O and frame hovers everywhere else - that is where `R[5]`'s *Part Count* comment comes from.

**You should see** the Problems panel list what ktrans would refuse, or report no problems.

[Check Before Compile](command:robotCode.karel.precheck)
