# RUKUS Is a Separate App

**Optional.** RUKUS is installed on its own; if you do not have it, skip this walkthrough.

RUKUS owns the things that need a connection held open: live monitoring, the alarm history, and scheduled backups. Robot Code is the editor and **hands off** to RUKUS instead of duplicating it.

**You should see** RUKUS's data folder open - or, if RUKUS is not installed, a prompt offering the download.

[Show RUKUS Data Folder / Get RUKUS](command:robotCode.rukus.revealData)
