# Get Some Programs

Robot Code reads registers, positions, macros and payloads straight from the files on disk - a folder of `.ls` / `.kl` programs, or a FANUC controller backup. Nothing connects to a robot for this.

Open a folder that holds your programs, add a backup folder for controller data, or try the bundled tutorial cell - a small two-robot cell with a snapshot, so the sync markers have something to show.

**You should see** the tutorial cell open in its own window, with `S002R01` and `S002R05` folders.

[Open the Tutorial Cell](command:robotCode.tutorial.open)
