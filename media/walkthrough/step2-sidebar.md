# Step 2: Explore the Sidebar

The Robot Code panel in the Activity Bar has 6 sections:

- **Controllers** -- live robot connections
- **Backup** -- loaded folder data
- **TP Programs** -- teach pendant programs
- **PC Programs** -- KAREL programs
- **Macros** -- macro definitions
- **Data** -- registers and I/O

Each section shows counts and status at a glance.

[Show Controllers View](command:robotCode.live.focusView)
