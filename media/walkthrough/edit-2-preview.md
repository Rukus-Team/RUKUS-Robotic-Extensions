# Read Tutorials as Previews

The walkthrough panel renders these notes for you, but a file like the tutorial cell's `README.md` opens as **source** by default.

Open it as a **Markdown preview** instead: press `Ctrl+Shift+V`, click the **Open Preview** icon, or right-click the file and choose **Open Preview**.

**You should see** a formatted page - headings and the tip block - instead of raw `#` marks.
