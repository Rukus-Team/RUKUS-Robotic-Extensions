# Teach a Position

Right-click a `P[n]` (or put the cursor in its block) and choose **Teach Position from Current Position…**.

One `CURPOS.DG` read, a confirmation showing every axis that moves and how far the tool centre point travels, then one undoable edit. Only the numbers that changed are rewritten.

**The file changes; the robot does not.** **You should see** the confirmation list the axes, then the `P[n]` numbers updated in place.

[Teach Position from Current Position…](command:robotCode.tp.teachPosition)
