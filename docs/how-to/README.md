# How-to guides

Task recipes. Each answers one question and stops. If you are learning the product for the
first time, start with the in-editor **walkthroughs** instead; if you want the reasons behind a
design, see the explanation docs linked from [`docs/README.md`](../README.md).

- [Move points you have already taught](offset-and-move-positions.md) - offset, set axis values, mirror, clean up
- [Change which frame a point is written against](frames.md) - convert, relabel
- [Restructure a program](refactor.md) - extract, inline, combine, remap a register
- [Understand a cell](analysis.md) - flow, call graph, cross-reference, unused programs, backup diff
- [Find out whether someone touched a program on the pendant](pendant-changes.md)
- [Set up a multi-robot cell container](cell-containers.md)
