# Robot Code documentation map

Four kinds of document, each doing one job (the [Diátaxis](https://diataxis.fr/) split). Start
with the walkthroughs if you are new; use how-to when you have a task; reference when you need a
fact; explanation when you want the reasons.

| You want to... | Go to | Where |
|---|---|---|
| Learn the product by doing | **Tutorials** - the in-editor walkthroughs (**Robot Code: Getting Started** on the Get Started page) | shipped in the extension |
| Do a specific task | **How-to** - [`docs/how-to/`](how-to/) | this repo |
| Look up a command or setting | **Reference** - the README, the Settings UI, and **What Can I Do Here?** (`Ctrl+Alt+H`) | README + extension |
| Understand a design decision | **Explanation** - the design notes below | this repo |
