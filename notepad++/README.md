# Robot Code for Notepad++

FANUC TP (`.ls`) and KAREL (`.kl`) support for Notepad++, generated from the Robot Code VS Code
extension so the two agree. VS Code remains the full tool; this is the base set for people who
live in Notepad++.

| What | Where it shows |
|---|---|
| Colouring for TP and KAREL | Language menu > **FANUC TP** / **FANUC KAREL** (picked automatically for `.ls` / `.kl`) |
| Folding | TP: `THEN`…`ENDIF`, `FOR`…`ENDFOR`. KAREL: `BEGIN`…`END`, `IF`, `FOR`, `WHILE`, `REPEAT`, `SELECT`, `CONDITION`, `STRUCTURE`, `USING` |
| Word completion | Ctrl+Space. KAREL built-ins (228) show their parameters and a one-line description as you type `(` |
| Function List | View > Function List: TP labels (`LBL[10:HOME]`), KAREL routines |
| Renumber, labels, format, strip, check | Run menu > **Robot Code: …** (Ctrl+Alt+Shift+R / L / F / S / K) - needs [Node.js](https://nodejs.org) 18 or later |

## Install

1. Close Notepad++ (it rewrites its settings when it closes, so the installer refuses to run while it is open).
2. Right-click `install.ps1` > **Run with PowerShell** (or `powershell -ExecutionPolicy Bypass -File install.ps1`).
   - The languages and Function List parsers go into `%APPDATA%\Notepad++`, plus two lines in `functionList\overrideMap.xml`.
   - The completion files have to go beside `notepad++.exe` (Notepad++ reads them nowhere else), so for an
     installed Notepad++ Windows asks once for admin rights to copy them into `Program Files\Notepad++\autoCompletion`.
   - `robotcode.js` goes into `%APPDATA%\Notepad++\robotcode`, and five **Robot Code: …** entries are added to the Run menu.
   - Portable Notepad++: `install.ps1 -Target <the folder with notepad++.exe>` (no admin needed).
3. Start Notepad++. **Notepad++ 8.9 and later** protect the Run menu: it shows a *Security Warning* that
   `shortcuts.xml` was modified and opens the file. Check the five `Robot Code: …` commands (each runs
   `node` on `robotcode.js` with the open file), then choose **Run > Validate shortcuts.xml**. Until you
   do, the Run menu commands do nothing; colouring, folding, completion and Function List work either way.
4. Open a `.ls` or `.kl` file.

Nothing else in Notepad++ is changed. Running `install.ps1` again updates everything in place.

## Uninstall

Close Notepad++, then run `uninstall.ps1` the same way (`-Target` for a portable one). It removes every file
and Run menu entry the installer added, and the two `overrideMap.xml` lines; Windows asks for admin
rights once to remove the completion files from the program folder.

## The Run menu (robotcode.js)

The same code the extension runs - the file comes out as the extension would write it.
A console window shows what was done; press a key to close it.

| Command | Does |
|---|---|
| **Renumber lines** (`renumber`) | Line numbers the controller's way (`--width 4`, `--no-semicolon`), `LINE_COUNT` updated |
| **Renumber labels** (`labels`) | Labels renumbered 10, 20, 30… with every `JMP LBL[]` following (`--start`, `--step`) |
| **Format /POS** (`format`) | `/POS` laid out as the controller writes it: three decimals, ten-character fields |
| **Copy without positions** (`strip`) | A copy without position data, `<name>_nopos.ls`, beside the file |
| **Check program** (`check`) | Jumps to missing labels, `P[]` used but not taught, taught but never used - nothing is edited |

**Save the file first** - the tool edits the file on disk, and Notepad++ then offers to reload it.
The shortcuts can be changed in Run > Modify Shortcut/Delete Command.

## Not here (VS Code only)

Hovers with register / I/O comments from a backup, cross-program references, the program views,
backup compare, teach from PR, positions tools, KAREL compile with ktrans, and anything that
talks to a robot.

Generated by `node scripts/make-notepadpp.mjs && node esbuild.mjs --npp` (`npm run notepadpp`) in
robot-code-vscode. Do not edit the XML by hand; change the generator or the extension's grammar.
